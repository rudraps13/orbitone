# Orbitone

A one-tap space game. You are a spark of light circling a planet, and every planet above you is asleep.

Tap to let go. Fly to the next planet and it wakes up in colour and plays a note. Wake enough of them and you're playing a song.

**Play:** open `index.html` in any browser, or visit the GitHub Pages link for this repository.

- **Tap** (click, touch or Space) to launch along the dotted line.
- Planets gently pull you in, so near misses still count.
- Fly straight in for a **Perfect** and build your combo.
- Collect gold stardust for extra points.

Glowing trails, shockwaves, screen shake and a soft space soundtrack. Every note is made live in the browser with the Web Audio API, so there are no sound files.

Made with HTML and JavaScript in a single file. No install, no build step.
